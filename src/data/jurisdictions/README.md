# CivicConnect — Indian Jurisdictions Architecture

## 1. Hierarchy Model
India -> State / Union Territory (36) -> District (750+) -> Sub-District (Mandal / Taluk / Tehsil / Taluka / Block / Circle / Subdivision)

## 2. Regional Terminology Mapping
- Telangana, Andhra Pradesh: Mandal
- Karnataka, Kerala, Tamil Nadu: Taluk
- Maharashtra, Gujarat, Goa: Taluka
- Uttar Pradesh, MP, Rajasthan, Haryana, Punjab, Uttarakhand, HP, Odisha: Tehsil
- Bihar, Jharkhand, Meghalaya: Block
- Assam, Arunachal Pradesh, Nagaland: Circle
- Delhi, Chandigarh, Sikkim, Mizoram, Tripura, Manipur, West Bengal: Subdivision
